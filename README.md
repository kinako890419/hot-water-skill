# 多喝熱水

> [多喝熱水機器人](https://github.com/kinako890419/plurk-hot-water-bot) 的 Agent Skills，但是不用 Plurk 和 Gemini API。

| Skill                 | 指令     | 功能                              |
| --------------------- | ------ | ------------------------------- |
| `hot-water`           | （任何訊息） | 機器人角色與指令分派、關鍵字快速回覆、今日運勢 |
| `hot-water-tarot`     | `!抽`   | 抽牌                              |
| `hot-water-complaint` | `!抱怨`  | 獲得一段沒同理心回覆                      |
| `hot-water-decide`    | `!要不要` | 隨機決定「要」或「不要」，並附上 30 字以內的理由      |
